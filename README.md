# shmuto.github.io

<https://shmuto.github.io> のランディングページ。GitHub Pages でホストしている
ツールへのリンクを置いています。

## 掲載しているツール

| ツール | 公開 URL | リポジトリ |
| --- | --- | --- |
| BGPShark | <https://shmuto.github.io/bgpshark/> | [shmuto/bgpshark](https://github.com/shmuto/bgpshark) |
| SNMP MIB Browser | <https://shmuto.github.io/mib-browser/> | [shmuto/mib-browser](https://github.com/shmuto/mib-browser) |
| difftaro | <https://shmuto.github.io/difftaro/> | [shmuto/difftaro](https://github.com/shmuto/difftaro) |

## 構成

ビルド不要の静的 HTML 1 枚 (`index.html`) です。ツールを追加するときは
`ul.tools` に `li.tool` を 1 つ足して、上の表も更新してください。
