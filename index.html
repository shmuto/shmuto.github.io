shmuto

ブラウザだけで動くネットワーク系のツールを置いています。
どれも入力したデータはサーバーに送られず、手元のブラウザ内だけで処理されます。

Tools

  • 🦈 BGPShark

    BGP セッションのトラブルシュートに特化した pcap アナライザ。OPEN / UPDATE / NOTIFICATION などを Wireshark を開かずに解析できます。

    GitHub

  • SNMP MIB Browser

    MIB ファイルをまとめて読み込み、1 つの OID ツリーにマージして閲覧・検索できる MIB ブラウザ。

    GitHub

  • difftaro

    ブラウザで完結する diff ツール。テキスト・ファイル・JSON の比較に対応し、 外部ライブラリもビルドも不要です。

    GitHub
